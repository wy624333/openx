# 隐私政策

**最后更新：2026 年 11 月 21 日**

OpenX 是一个本地优先的 AI 客户端。本政策说明本应用如何处理你的信息，请在使用前阅读。

## 一、核心原则

1. **本应用不设服务器，不收集、不上传你的任何数据到开发者处。**
2. 本应用**不集成任何第三方统计、广告、用户画像或崩溃上报 SDK**。
3. 你的数据默认只保存在本机。是否外发、发往何处，完全由你配置和触发。

## 二、本机保存的信息

以下信息保存在应用私有目录，卸载应用即删除（除非你另行备份）：

| 类别 | 内容 | 用途 |
|---|---|---|
| 会话数据 | 对话记录、消息、附件路径、工具调用记录 | 提供聊天与历史功能 |
| 配置信息 | 模型服务商地址与 API Key、偏好设置、外观设置 | 调用你所选的模型服务 |
| 凭据 | Git 凭据、SSH 私钥、远程服务器配置 | 你主动发起的代码托管与远程连接 |
| 知识库 | 你导入或沉淀的知识条目 | 本地检索增强 |
| 插件数据 | 各插件的配置与状态 | 插件功能运行 |
| 运行日志 | 命令输出、错误日志 | 排查问题，仅存本机 |

这些文件位于应用沙盒内，其它应用无法直接读取。Android 系统备份若开启，可能随系统备份机制同步，可在系统设置中关闭。

## 三、会外发数据的情形

以下情形会将数据发送到**你指定的第三方**，均由你的操作触发：

1. **调用 AI 模型**：你发送的消息、附带的上下文（文件内容、终端输出、图片等）会发送到你配置的模型服务商。数据处理方式受该服务商隐私政策约束。
2. **获取行情数据**：股票代码等查询参数会发送到公开行情接口（如东方财富、腾讯、新浪财经）。
3. **下载模型或资源**：会向 HuggingFace、ModelScope、GitHub 等地址发起请求。
4. **Git 与远程连接**：向你的代码托管平台或服务器发送提交内容与认证信息。
5. **插件联网**：插件声明的 `http` 权限允许其访问网络，具体目标由插件决定。建议只安装你信任的插件。
6. **检查更新**：仅请求 `version.json` 版本号文件，不携带任何个人信息。

**敏感信息提示**：如果你在对话中包含密钥、身份证号、住址等内容，这些内容会随请求发送给模型服务商。请自行判断是否适合发送。

## 四、敏感信息保护

1. 本应用内置**出站脱敏**机制，在请求发出前对识别到的敏感信息（如手机号、身份证号、银行卡号、密钥等）做掩码处理。
2. 脱敏按规则匹配，无法保证覆盖全部敏感内容。**请勿依赖此机制替代你自己的判断。**
3. API Key、SSH 私钥等凭据以本机文件形式保存，应用会尽力限制其访问权限，但**未做额外加密**。设备被 root、被他人物理接触或系统存在漏洞时，存在泄露风险。

## 五、系统权限

本应用申请的权限均用于对应功能，不使用时会关闭或不予授予：

| 权限 | 用途 |
|---|---|
| 网络 | 调用模型、行情、下载资源 |
| 存储 | 读写工作区文件、导入导出 |
| 麦克风 | 语音输入（仅在你主动录音时） |
| 悬浮窗 | 插件悬浮面板（如设备监控常驻显示） |
| 辅助功能 / Shizuku | 执行你授权的系统级操作 |
| 通知 | 长任务完成、服务状态提醒 |

权限可随时在系统设置中撤回，撤回后对应功能将不可用。

## 六、本地容器

本应用在设备上运行一个本地 Linux 环境（PRoot/Alpine），用于执行命令、运行插件服务。该环境中的数据同样只存在本机。你在其中安装的软件、下载的文件由你自行管理。

## 七、第三方链接

本应用可能打开第三方网页（如 GitHub、许可证页面）。这些站点的数据处理不受本政策约束，请查阅其各自的隐私政策。

## 八、未成年人

本应用不面向 14 周岁以下未成年人。若你为未成年人，请在监护人指导下使用。

## 九、你的权利

1. **查看与导出**：可在应用内查看会话、配置等数据，并通过备份功能导出。
2. **删除**：可删除单条会话、清空知识库、重置容器，或卸载应用以删除全部本机数据。
3. **撤回授权**：可随时在系统设置中关闭权限。

由于开发者不收集你的数据，无需也无法向开发者申请查询、更正或删除你的个人信息。

## 十、政策变更

本政策随版本更新调整，更新后随新版本发布。涉及数据处理的重大变更会在更新说明中注明。

## 十一、联系方式

对本政策有疑问，可通过「意见反馈」渠道提出。
